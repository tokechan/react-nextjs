# フォーム実装比較：useState vs React Hook Form

## 🧠 概要

同じフォームを `useState` を使った自作版と、`React Hook Form`（RHF）を使った版で実装し、違いを比較した。

---

## 🔀 比較表

| 比較項目       | useState 版                | RHF 版                           |
| -------------- | -------------------------- | -------------------------------- |
| 状態管理       | useState を各項目に定義    | register で自動管理される        |
| バリデーション | if 文で手動チェック        | バリデーションルールを登録で定義 |
| エラー表示     | useState(errors)で制御     | `formState.errors` で取得可能    |
| コード量       | やや多め（状態管理が冗長） | コンパクト＆宣言的               |
| 可読性         | ロジックがやや散らばる     | 入力とバリデーションが近い       |

---

## 📌 気づき

- RHF は複数フィールドでも状態管理がめちゃ楽。
- 手動版はフォーム構造や処理の流れを理解するには最適。
- 自作 → ライブラリ化の順でやると、ライブラリの恩恵がよくわかる！
